# AI model, API and runtime retirement dates

Every dated AI model retirement, provider API removal and runtime end of life that [Since.dev](https://since.dev) tracks, with the replacement where there is one and the source that states it. Updated daily.

As of Nov 10, 2026: 8,742 dates across 494 providers, 582 for AI models, 56 for provider APIs and 8,104 for runtimes and other software.

A model often retires on different dates on different platforms (the provider's own API, Azure, Amazon Bedrock, Google Vertex AI), so each platform's date is its own entry.

## Files

| File | What it holds |
| --- | --- |
| [`data/all.json`](data/all.json) | Every date, soonest first |
| [`data/all.csv`](data/all.csv) | The same as CSV |
| [`data/models.json`](data/models.json) | AI models only |
| [`data/apis.json`](data/apis.json) | Provider APIs only |
| [`data/runtimes.json`](data/runtimes.json) | Runtimes, languages, frameworks, databases and other software |
| [`data/providers/`](data/providers) | One file per provider, such as `openai.json` |
| [`data/schema.json`](data/schema.json) | The JSON Schema of one entry |

Each JSON file is an array with one entry per line.

## Use it

- Raw file: `https://raw.githubusercontent.com/Since-dev/retirements/main/data/all.json`
- Calendar to subscribe to: `https://api.since.dev/v1/calendar.ics`, or RSS at `https://api.since.dev/v1/calendar.rss`
- API, free and without a key: `https://api.since.dev/v1/calendar?kind=model`
- In a coding agent, Since.dev's MCP server checks your code against these dates: `https://api.since.dev/mcp`
- For any public GitHub repository, a scan shows which of these dates its code hits: [since.dev/scan](https://since.dev/scan)

```sh
curl -s https://raw.githubusercontent.com/Since-dev/retirements/main/data/models.json | jq '.[] | select(.provider == "openai" and .date >= "2026-11-10") | {modelId, date, replacement}'
```
